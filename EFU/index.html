EFU — ESP Flash Utility

Browser-based ESP flasher using the Web Serial API. No server, no install — just open and flash.

Supported chips:

  • ESP32, ESP32-S2, ESP32-S3
  • ESP32-C2, ESP32-C3, ESP32-C6, ESP32-H2
  • ESP8266

Operations: Write, Erase, Erase+Write, Chip ID, Flash ID, Verify, MAC Read, Hard Reset, Read Flash

Requirements: Chrome/Edge 89+ on desktop. The ESP device must be connected via USB and in bootloader mode (hold BOOT, press RESET).

Based on SkorpioX22/espflashutility — esptool.py protocol implemented in JavaScript.
